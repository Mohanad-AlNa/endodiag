# EndoDiag

واجهة ويب عربية مبدئية لدعم قراءة الصور الشعاعية الذروية في المداواة اللبية.

## الميزات
- صفحة رئيسية توضّح فكرة المشروع مع الإسناد إلى د. مهند النشواتي.
- رفع صورة شعاعية ذروية ومعالجتها داخل المتصفح.
- تحديد مناطق مشتبهة (مثل تبدلات قرب الذروة أو مناطق انخفاض الكثافة) مع نسبة ثقة تقريبية.
- أداة تقدير الطول العامل التقريبي بالاعتماد على معايرة (مم/بكسل).
- تصدير صورة النتائج مع التحديدات.

## التشغيل
بما أن المشروع واجهة ثابتة، افتح `index.html` مباشرة أو عبر أي خادم ملفات ثابتة.
